Set up the admin password (one time)

This needs a GitHub token once. The token is encrypted with the password you choose and stored on the site; after that only the password is needed.

  1. Open GitHub → New fine-grained token. Choose an expiry (e.g. 1 year).
  2. Repository access: Only select repositories → vinayarya29/vinayarya29.github.io.
  3. Permissions: Contents → Read and write.
  4. Generate, copy and paste it below, then choose a password.
