LabNotebook — Privacy Policy

Last updated: 7 November 2026

LabNotebook is a personal lab-management application written and used by Dr. Vinay Arya. It runs only on the owner's own computer and is not offered to the public.

Google Calendar access

With the owner's permission, LabNotebook uses the Google Calendar API to create, update and delete events in a single calendar named “LabNotebook” in the owner's own Google account. These events mirror the tasks and meetings recorded in the app. LabNotebook does not read, change or delete any other calendar.

Data storage and sharing

  • All data, including the Google sign-in token, is stored only on the owner's computer.
  • No data is sent to any server other than Google's Calendar API.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

LabNotebook's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from Google Account → Third-party connections. You can also delete the “LabNotebook” calendar.
